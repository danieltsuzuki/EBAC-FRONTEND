# README - Tsuzuki Tech

## Sobre o projeto

O **Tsuzuki Tech** é um blog desenvolvido com Next.js focado em desenvolvimento moderno, programação e tecnologia.

O projeto possui:

- Renderização híbrida (SSR/SSG)
- SEO com metadata dinâmica
- Paginação de artigos
- Rotas dinâmicas
- Layout responsivo
- Otimização de imagens
- Deploy na Vercel

---

# Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS

---

# Como rodar o projeto

## 1. Clone o repositório

```bash
git clone <URL_DO_REPOSITORIO>
```

---

## 2. Acesse a pasta

```bash
cd nome-do-projeto
```

---

## 3. Instale as dependências

```bash
npm install
```

ou

```bash
yarn
```

---

## 4. Execute o projeto

```bash
npm run dev
```

ou

```bash
yarn dev
```

---

## 5. Abra no navegador

```txt
http://localhost:3000
```

---

# Build de produção

```bash
npm run build
```

---

# Executar produção localmente

```bash
npm start
```
